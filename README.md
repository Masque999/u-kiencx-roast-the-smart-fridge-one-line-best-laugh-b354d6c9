# Roast the Smart Fridge: One Line, Best Laugh Wins

One line, at most 160 characters: roast the smart fridge, best laugh wins.

Entry: `My smart fridge judges my midnight snacks out loud, then locks the ice cream drawer and calls it tough love.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
